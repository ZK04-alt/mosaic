# Mosaic

[Mosaic for Android](https://zk04-alt.github.io/mosaic/app/)

[Download the APK](https://github.com/ZK04-alt/mosaic/releases/download/android-1.0.4-build11/Mosaic-1.0.4-build11.apk)

Mosaic brings study plans, recorded study time, practice papers and saved
questions together. The current download is version 1.0.4, build 11.

## Project and development

Mosaic is a personal project by Muhammad Zunair.

I defined Mosaic's study workflows and made the product, visual and creative
decisions. AI implemented the graphical interface and assisted with Android
development under my direction.

This repository contains the public static website and distributes the Android
installer through Releases. It does not contain backend credentials, private
records or the complete Android application source. Website source archives
contain the public website only. Third-party notices are in licenses/.
